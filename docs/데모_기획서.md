# Auric Loop H.I.P. 데모 기획서 (Claude안)

작성일: 2026-10-04 · 대상 행사: H.I.P. 2026 (10월 30일~11월 1일, 홍대 미진플로어)

이 문서는 회사 자료를 바탕으로 Claude가 데모를 어떻게 만들지 정리한 안입니다. 주인님 생각과 다른 곳을 찾기 쉽도록 각 항목에 출처 표시를 붙였습니다.

- **[기획]** 회사 기획 자료에 있는 내용입니다. 제안서 v2.0(260504), 제안서 v3(260606), 기획 회의록, 0606 내부실무회의, 게임 소개서, 캐릭터 설정화가 해당됩니다.
- **[제안]** 자료에 없어서 Claude가 정한 내용입니다. 다르면 고쳐 주세요.
- **[결정]** 주인님이 10월 4일에 정해 주신 내용입니다.

## 2. 데모 한 판의 흐름

```
타이틀 → 캐릭터 선택 → 오프닝 대화 → 거점(중앙 광장)
  → (자유) 원룸 · NPC 구역 둘러보기
  → 던전 1층: 전투방 ×2 → 채집방 → 상점(대장간) → 보스방
  → [귀환] 사용 → 귀환 페이즈(되돌아가기) → 거점 도착
  → 정산(빚 상환) → 거점 자유 시간(번 골드로 NPC 이용) → 엔딩 카드(Coming Soon)
```

원룸과 NPC 구역도 데모에 넣습니다. 데모가 끝났다고 막지 않고, 보여 줄 수 있는 것은 다 보여 줍니다. [결정]

**기획팀 의견 반영 (10/05) [결정]:** 거점과 NPC 구역은 "이런 느낌이다" 정도로만 만들고 던전 구현에 힘을 쏟습니다. NPC는 빚 상환(수금원)과 인테리어 상인만 동작하고, 나머지 상인은 "휴가 중", "가게 개장 준비 중" 표지판만 세웁니다.

| 단계 | 시간 | 가르치는 것 | 출처 |
| --- | --- | --- | --- |

## 3. 맵

### 3-1. 거점 [기획: 거점 계획 도식]

```
              [ 마몬의 입 (던전 입구) ]
                       ▲
                  [ 높은 계단 ]
                       │
[ 원룸 ] ─────── [ 중앙 광장 ] ─────── [ NPC 구역 ]
(개인 정비·가구)  (부채 전광판)          (NPC 6명)
```

- 플레이어는 광장 아래쪽에서 시작합니다. [기획: "시작하면 위쪽으로 이동"]
- 부채 전광판에 캐릭터 얼굴과 남은 빚이 주유소 가격판처럼 보입니다. [기획]
- 원룸과 NPC 구역 모두 들어갈 수 있습니다. 동작하는 NPC는 수금원과 인테리어 세공사 둘입니다. [결정: 기획팀 10/05]

**원룸 [기획: 거점 설계]**
- 처음에는 소형 방 크기의 비좁고 낡은 원룸입니다. 소파·침대·냉장고·TV가 있습니다.
- 가구를 조사하면 대화창으로 설명이 나옵니다. 예: "꺼진 TV. 화면에 비친 내 얼굴이 피곤해 보인다."
- 소파 업그레이드(골드, 체력 +1, 최대 3회)를 실제로 할 수 있습니다. 데모 가격은 50골드입니다. [제안: 가격]
- 침대·냉장고·TV 커스텀은 유료 재화 기능이라 "준비 중"으로 표시합니다. [제안]

**NPC 구역 [기획: NPC 구역 설명]**

| NPC | 데모에서 하는 일 | 출처 |
| --- | --- | --- |
| 수금원 | 남은 빚 안내, 골드를 원하는 만큼 추가 상환 | [기획] |
| 인테리어 세공사 | 원룸 Lv1→Lv2 공사, 피로도 한계 상승. 데모 가격 150골드 | [기획] [제안: 가격] |
| 가방 렌탈 상인 | 가게만 있고 "휴가 중" 표지판 | [결정: 기획팀 10/05] |
| 부적 상인 | 가게만 있고 "가게 개장 준비 중" 표지판 | [결정: 기획팀 10/05] |
| 제작서 상인 | 가게만 있고 "가게 개장 준비 중" 표지판 | [결정: 기획팀 10/05] |
| 유물 감정사 | 가게만 있고 "휴가 중" 표지판 | [결정: 기획팀 10/05] |

- 시작 골드는 0입니다. 던전 전에 살 물건이 없어서 시작 골드를 없앴습니다. [결정: 기획팀 10/05에 따라 수정]
- 귀환 뒤 거점 자유 시간에는 번 골드로 추가 상환·공사·소파 업그레이드를 해 볼 수 있습니다. [제안]

### 3-2. 던전 1층 (데모 전용 고정 배치) [제안]

본편 1층은 전투방 10개를 무작위로 생성합니다. [기획] 데모는 시간 안에 끝나야 하므로, 손으로 배치한 방 5개를 한 줄로 잇습니다.

```
[입구] → [전투방1 중형] → [전투방2 중형] → [채집방 소형] → [상점 중형] → [보스방 대형]
```

| 방 | 크기 | 내용 |
| --- | --- | --- |
| 전투방1 | 중형 | 근거리 해골 3마리 |
| 전투방2 | 중형 | 근거리 해골 2마리, 원거리 해골 2마리. 마지막 해골이 마물형 소재 1개를 확정으로 떨굼 [제안: 인챈트 체험용] |
| 채집방 | 소형 | 채집 지점 2개(1층 기준) [기획]: 광물 바위 1개, 약초 덤불 1개(채집 한 번에 약초 3개). 빈 병은 오프닝에서 수금원이 제작서와 함께 1개 줌 [제안] |
| 상점방 | 중형 | 판매대(체력 회복 물약, 피로도 회복 물약) + 대장장이(강화). 패시브 아이템은 데모에서 뺌 [기획] [결정: 기획팀 10/05 패시브는 없거나 3개 이하] |
| 보스방 | 대형 | 1층 보스 해골 대장 [결정] |

- 방은 정사각형이고 소형 4×4, 중형 6×6, 대형 8×8입니다. [기획]
- 1칸 = 4m입니다. [결정] 중형 방(24m)을 이동속도 6으로 4초에 건너므로 기획의 "방 끝에서 끝까지 3~5초"와 맞습니다.
- 도트 크기는 1m = 32px, 1칸 = 128px로 합니다. 카메라는 도트를 2배로 키워 1280×720 화면에 20m×11.25m를 보여 줍니다(1080p에서는 3배). 엔터 더 건전·소울 나이트처럼 플레이어를 따라가면서 조준 방향으로 최대 3m 끌려갑니다. [결정 10/05: "카메라가 너무 축소된 느낌" 반영, 이전 40m×22.5m]
- 전투방에 들어가면 문이 잠기고, 적을 다 잡으면 열립니다. [제안]

### 4-1. 공통 스테이터스 [기획: 제안서 v2.0]

| 항목 | 값 |
| --- | --- |
| 체력 | 3 (일반 적 피격 -1, 황금 적 -2) |
| 공격력 | 1 (피해 = 무기공격력 × 공격력) |
| 이동속도 | 6 |
| 피로도 한계 | 100. 방 클리어 +1, 보스 +2, 채집 +1, 75% 이상이면 이동속도 -25%·공격력 -10%, 가득 차면 게임 오버 |
| 적재량 | 100. 초과하면 이동속도 -25%, 방 클리어 때 피로도 +1 추가 |
| 크리티컬 | 확률 1%, 피해 2배 |
| 회피 | 바라보는 방향으로 1초 대시, 이동속도 2배, 무적, 쿨타임 2초 |

**데모 보정 [결정]:** 데모 한 판에서 피로도는 8~10밖에 오르지 않아 압박이 없습니다. 그래서 피로도 한계를 `balance.json`의 `fatigue_max` 변수로 두고 데모 기본값을 20으로 합니다. 정상 진행 때 귀환 직전 75% 근처에 닿아 "지치기 전에 돌아가야 한다"를 체감하게 됩니다. 행사 현장에서도 이 값만 바꿔 난이도를 조정할 수 있습니다.

### 4-2. 무기 수치 [제안, `balance.json`에서 조정]

| 무기 | 무기공격력 | 공격 간격 | 사거리 | 일반 해골(체력 3.5) 처치 |
| --- | --- | --- | --- | --- |
| 검 | 1.0 | 0.35초 | 부채꼴 반경 2.5m, 각도 100° | 4대 [기획 기준선: 3~4대] |
| 활 | 2.5 | 1초 장전 | 직선 20m | 2발 |
| 지팡이 | 0.5 + 폭발 0.3 (반경 1.2m) | 0.15초 | 직선 12m | 5~7발 |

- 강화 +1마다 무기공격력이 15% 오릅니다. 데모에서는 +1만 할 수 있습니다. [제안 수치, 기획: 층마다 1회]
- 차징 공격은 데모에서 뺍니다. 기획에도 "일부 무기"로만 적혀 있어 어느 무기인지 정해지지 않았습니다. [제안]

### 6-3. 귀환 페이즈 [기획: 제안서 v2.0 귀환]

1. 보스를 잡으면 가방에 [귀환] 아이템이 생깁니다.
2. 아이템을 쓰면 화면이 붉게 바뀌고 귀환 페이즈가 시작됩니다.
3. 지나온 방을 거꾸로 걸어서 돌아갑니다. 각 방에 무적 적이 한꺼번에 나타납니다.
4. 다음 방으로 가는 문은 잠겨 있고, 10번 공격하면 열립니다. 열리는 순간 적 전체가 1초 스턴됩니다.
5. 상호작용 키가 [섬광탄]으로 바뀝니다. 쓰면 1초 전체 스턴과 탄막 제거가 되고, 골드 10이 듭니다. [제안: 가격]
6. 귀환 중에는 채집·상점·NPC를 쓸 수 없고, 방을 지날 때마다 피로도가 +1 됩니다.
7. 입구에 도착하면 귀환 성공입니다.

데모는 귀환 경로를 보스방에서 입구까지 방 5개 전부로 합니다. 시간이 길면 3개로 줄입니다. [제안]

### 6-4. 정산 [기획]

- 소재가 자동으로 골드로 바뀝니다.
- 획득 골드의 일부가 빚 상환으로 자동 차감됩니다.
- 무기 강화는 초기화됩니다.
- 부채 전광판의 숫자가 줄어드는 연출을 보여 줍니다.
- 캐릭터별 빚과 상환 비율은 Claude가 정했습니다. [결정: Claude에게 맡김] 두 값 모두 `balance.json` 변수입니다.

| 캐릭터 | 빚 총액 | 이유 |
| --- | --- | --- |
| 발렌 | 9,800골드 | 여자에게 속아 잃은 돈. 셋 중 가장 적음 |
| 셰리 | 14,500골드 | 취했을 때 생긴, 본인도 이유를 모르는 빚 |
| 알레아 | 31,700골드 | 무작위성 연구에서 시작된 도박 빚. 가장 많음 |

- 상환 비율은 50%입니다. 데모 한 판에서 버는 골드는 약 150~250골드입니다. 그래서 75~125골드가 빚에서 빠지고, 전광판 숫자가 실제로 줄어드는 것이 보입니다.
- 빚을 수천 골드 단위로 잡은 이유가 있습니다. 수백만 단위면 한 판으로 줄어드는 양이 너무 작아 보이지 않습니다.

### 6-5. 대화창 [제안]

모든 대사(오프닝, NPC, 가구 조사, 안내)는 같은 대화창 하나로 보여 줍니다.

```
┌──────────────────────────────────────────────┐
│ [초상화]  수금원                               │
│ [ 64px ]  "이번 주 이자는 아직이던데?"          ▼ │
└──────────────────────────────────────────────┘
```

- 화면 아래쪽에 도트 테두리 창을 띄웁니다. 왼쪽에 초상화(64×64px), 위에 이름, 그 아래 본문이 들어갑니다.
- 글자는 한 글자씩 나옵니다. 클릭이나 E를 누르면 바로 다 나오고, 한 번 더 누르면 다음 대사로 넘어갑니다.
- 선택지는 최대 3개입니다. 예: [갚는다] [나중에]. 마우스나 W/S와 E로 고릅니다.
- 대화 중에는 플레이어가 멈춥니다. 단, 전투방 안내 말풍선은 게임을 멈추지 않고 작게 띄웁니다.
- 대사는 `dialogue.json` 하나에 모아 둡니다. 그래서 코드를 고치지 않고 문구만 바꿀 수 있습니다.

### 8-1. 화면 크기 대응 [결정: 모니터와 상관없이 맞게]

**게임 월드**
- 세로 22.5m(720px)가 항상 보이게 고정하고, 화면 높이에 맞춰 키웁니다. 720p는 1배, 1440p는 2배로 정수배입니다. 1080p(1.5배)처럼 정수가 아닌 배율은 UI처럼 SVG가 없으므로 가장 가까운 정수배와 테두리를 쓰거나, 화질을 보고 정합니다.
- 높이가 720의 정수배가 아니면 남는 픽셀은 위아래 어두운 테두리로 둡니다. [확인 필요: 1080p 모니터 화질]
- 가로는 화면 비율만큼 더 보여 줍니다. 16:9에서 40m, 21:9에서 약 52m이고, 21:9를 넘으면 양옆에 테두리를 둡니다.

**UI**
- 모든 UI는 화면 모서리 기준으로 붙입니다(앵커). HP·피로도·적재량은 왼쪽 위, 가방·일시정지·미니맵은 오른쪽 위, "탐색 1F"는 위쪽 가운데, 버튼은 오른쪽 아래, 조이스틱은 왼쪽 아래입니다.
- 크기는 "화면 높이 ÷ 720" 배율로 맞춥니다.
- 키트에 모든 부품의 SVG가 있습니다. 그래서 1.5배처럼 정수가 아닌 배율에서도 SVG를 쓰면 도트 모양이 깨지지 않고, 정수배일 때는 PNG를 nearest로 씁니다.
- 글자는 이미지가 아니라 글자 객체(Noto Sans KR)라 어떤 크기에서도 선명합니다.
- 노치·둥근 모서리 화면에서는 안전 영역 안쪽에 둡니다(모바일 대비).

**엔진 지원:** HBEngine UI 에셋에 이미 앵커, 기준 크기(1280×720), scaleMode(constant/scale), 안전 영역 설정이 있습니다(`prototype/ui-assets.js`). SVG를 정수가 아닌 배율로 그렸을 때 도트가 선명한지는 실제 창에서 확인해야 합니다.

| 기능 | 방법 |
| --- | --- |
| 이동 | TopDownMovement2D (시험 실행 확인) |

| 탄환·적 | Spawn Actor가 기본 도형만 만들 수 있습니다. 그래서 장면에 미리 배치한 객체를 재사용(풀링)합니다 (시험 실행 확인) |
| 검 베기 | Overlap Sphere와 내적으로 부채꼴을 판정합니다 |
| 회피·쿨타임·장전 | 타이머와 변수 |

| 구조 (10/06, 엔진 P0 반영) | 게임 규칙은 C++ `TopDownShooter`(장면마다 Director). 적은 BP 상속(`BP_Enemy` → 해골·해골 마법사·해골 대장)이고 행동은 상태 머신(`Assets/AI/FSM_*`)이 정한다. 상태마다 BP 사용자 이벤트가 C++ `Enemy` 함수를 부른다.
