# Auric Loop H.I.P. 데모 기획서 (Claude안)

작성일: 2026-10-04 · 대상 행사: H.I.P. 2026 (10월 30일~11월 1일, 홍대 미진플로어)

이 문서는 회사 자료를 바탕으로 Claude가 데모를 어떻게 만들지 정리한 안입니다. 주인님 생각과 다른 곳을 찾기 쉽도록 각 항목에 출처 표시를 붙였습니다.

- **[기획]** 회사 기획 자료에 있는 내용입니다. 제안서 v2.0(260504), 제안서 v3(260606), 기획 회의록, 0606 내부실무회의, 게임 소개서, 캐릭터 설정화가 해당됩니다.
- **[제안]** 자료에 없어서 Claude가 정한 내용입니다. 다르면 고쳐 주세요.

## 2. 데모 한 판의 흐름

```
타이틀 → 캐릭터 선택 → 거점(중앙 광장) → 던전 1층
  → 전투방 ×2 → 채집방 → 상점(대장간) → 보스방
  → [귀환] 사용 → 귀환 페이즈(되돌아가기) → 거점 도착
  → 정산(빚 상환) → 엔딩 카드(Coming Soon)
```

| 단계 | 시간 | 가르치는 것 | 출처 |
| --- | --- | --- | --- |
| 1. 타이틀 | 10초 | 로고, 시작 | [제안] |
| 2. 캐릭터 선택 | 30초 | 발렌·셰리·알레아 중 1명 | [기획: 튜토리얼에서 셋 중 하나 선택] |
| 3. 거점 | 40초 | 이동, 부채 전광판, 던전 입구 | [기획: 거점 구조] |
| 4. 전투방 1 | 1분 | 조준, 공격, 회피 | [제안: 방 구성] |
| 5. 전투방 2 | 1분 | 원거리 탄막 피하기, 피로도 증가 | [기획: 적 2종, 방 클리어 피로도 +1] |
| 6. 채집방 | 40초 | 상호작용·채집, 적재량 | [기획: 비전투방, 채집] |
| 7. 상점방 | 1분 | 대장장이 강화 +1, 회복 아이템 | [기획: 층마다 상점·대장장이] |
| 8. 보스방 | 1분 30초 | 보스 처치, [귀환] 아이템 획득 | [기획: 귀환 최소 조건 = 보스 처치] |
| 9. 귀환 페이즈 | 1분 30초 | 무적 적 회피, 잠긴 문 10회 공격, 섬광탄 | [기획: 귀환 규칙] |
| 10. 정산 | 40초 | 소재→골드, 빚 자동 상환, 강화 초기화 | [기획: 정산 규칙] |
| 11. 엔딩 카드 | 10초 | 게임 소개, 인스타·위시리스트 QR | [제안] |

게임 오버(체력 0 또는 피로도 가득) 처리는 이렇게 합니다.
- "빈손으로 끌려 나왔다"는 화면을 보여 주고 정산 단계로 갑니다. 이때 들고 있던 소재는 잃습니다. [제안]
- 강화는 초기화됩니다. [기획: 게임 오버 때도 강화 초기화]

## 3. 맵

### 3-1. 거점 [기획: 거점 계획 도식]

```
              [ 마몬의 입 (던전 입구) ]
                       ▲
                  [ 높은 계단 ]
                       │
[ 원룸 ] ─────── [ 중앙 광장 ] ─────── [ NPC 구역 ]
(데모: 잠김)     (부채 전광판)         (데모: 간판만)
```

- 플레이어는 광장 아래쪽에서 시작합니다. [기획: "시작하면 위쪽으로 이동"]
- 부채 전광판에 캐릭터 얼굴과 남은 빚이 주유소 가격판처럼 보입니다. [기획]
- 원룸과 NPC 구역은 데모에서 들어가지 못합니다. "준비 중" 간판만 둡니다. [제안: 시간 절약]

### 3-2. 던전 1층 (데모 전용 고정 배치) [제안]

본편 1층은 전투방 10개를 무작위로 생성합니다. [기획] 데모는 시간 안에 끝나야 하므로, 손으로 배치한 방 5개를 한 줄로 잇습니다.

```
[입구] → [전투방1 중형] → [전투방2 중형] → [채집방 소형] → [상점 중형] → [보스방 대형]
```

| 방 | 크기 | 내용 |
| --- | --- | --- |
| 전투방1 | 중형 | 근거리 해골 3마리 |
| 전투방2 | 중형 | 근거리 해골 2마리, 원거리 해골 2마리 |
| 채집방 | 소형 | 광물 1개, 식물 1개 (채집 소재 수는 1층 기준 2개) [기획] |
| 상점방 | 중형 | 대장장이, 체력 회복 물약, 피로도 회복 물약 [기획] |
| 보스방 | 대형 | 1층 보스 |

- 방은 정사각형이고 소형 4×4, 중형 6×6, 대형 8×8입니다. [기획]
- 1칸 = 4m(타일 4×4개)로 보면, 중형 방(24m)을 이동속도 6으로 4초에 건넙니다. 기획의 "방 끝에서 끝까지 3~5초"와 맞습니다. [제안: 칸 크기 해석]
- 전투방에 들어가면 문이 잠기고, 적을 다 잡으면 열립니다. [제안]

### 4-1. 공통 스테이터스 [기획: 제안서 v2.0]

| 항목 | 값 |
| --- | --- |
| 체력 | 3 (일반 적 피격 -1, 황금 적 -2) |
| 공격력 | 1 (피해 = 무기공격력 × 공격력) |
| 이동속도 | 6 |
| 피로도 한계 | 100. 방 클리어 +1, 보스 +2, 채집 +1, 75% 이상이면 이동속도 -25%·공격력 -10%, 가득 차면 게임 오버 |
| 적재량 | 100. 초과하면 이동속도 -25%, 방 클리어 때 피로도 +1 추가 |
| 크리티컬 | 확률 1%, 피해 2배 |
| 회피 | 바라보는 방향으로 1초 대시, 이동속도 2배, 무적, 쿨타임 2초 |

**데모 보정 [제안]:** 데모 한 판에서 피로도는 8~10밖에 오르지 않아 압박이 없습니다. 그래서 데모에서만 피로도 한계를 20으로 낮춥니다. 그러면 정상 진행 때 귀환 직전 75% 근처에 닿아 "지치기 전에 돌아가야 한다"를 체감하게 됩니다.

### 4-2. 무기 수치 [제안, `balance.json`에서 조정]

| 무기 | 무기공격력 | 공격 간격 | 사거리 | 일반 해골(체력 3.5) 처치 |
| --- | --- | --- | --- | --- |
| 검 | 1.0 | 0.35초 | 부채꼴 반경 2.5m, 각도 100° | 4대 [기획 기준선: 3~4대] |
| 활 | 2.5 | 1초 장전 | 직선 20m | 2발 |
| 지팡이 | 0.5 + 폭발 0.3 (반경 1.2m) | 0.15초 | 직선 12m | 5~7발 |

- 강화 +1마다 무기공격력이 15% 오릅니다. 데모에서는 +1만 할 수 있습니다. [제안 수치, 기획: 층마다 1회]
- 차징 공격은 데모에서 뺍니다. 기획에도 "일부 무기"로만 적혀 있어 어느 무기인지 정해지지 않았습니다. [제안]

## 6. 시스템

### 6-1. 재화와 소재

| 종류 | 데모에서 얻는 곳 | 무게 | 정산 가치 | 출처 |
| --- | --- | --- | --- | --- |
| 골드 | 적 처치 1~3, 보스 30 | 0 | 그대로 | [제안: 수치] |
| 광물형 | 채집방 | 30 | 40 골드 | [기획: 가장 무겁고 비쌈] [제안: 수치] |
| 식물형 | 채집방 | 5 | 5 골드 | [기획: 가장 가볍고 쌈] [제안: 수치] |
| 동물형 (마물형) | 적 처치 4% (데모는 보스가 확정 1개) | 15 | 30 골드 | [기획: 4%] [제안: 데모 확정 드롭] |

광물을 두 개 들면 적재량(100)을 넘습니다. 그래서 무게 때문에 느려지는 것을 한 번 보여 줄 수 있습니다. [제안]

### 6-2. 대장간 강화 [기획]

- 상점방의 대장장이에게 골드를 내고 무기공격력을 올립니다. 데모 가격은 20골드입니다. [제안]
- 강화하면 무기 이름 뒤에 +N이 붙습니다. +5부터 황금 무기지만, 데모는 +1까지만 합니다.
- 인챈트는 데모에서 뺍니다. 화면에 "마물형 소재로 인챈트 가능" 안내 한 줄만 보여 줍니다. [제안]

### 6-3. 귀환 페이즈 [기획: 제안서 v2.0 귀환]

1. 보스를 잡으면 가방에 [귀환] 아이템이 생깁니다.
2. 아이템을 쓰면 화면이 붉게 바뀌고 귀환 페이즈가 시작됩니다.
3. 지나온 방을 거꾸로 걸어서 돌아갑니다. 각 방에 무적 적이 한꺼번에 나타납니다.
4. 다음 방으로 가는 문은 잠겨 있고, 10번 공격하면 열립니다. 열리는 순간 적 전체가 1초 스턴됩니다.
5. 상호작용 키가 [섬광탄]으로 바뀝니다. 쓰면 1초 전체 스턴과 탄막 제거가 되고, 골드 10이 듭니다. [제안: 가격]
6. 귀환 중에는 채집·상점·NPC를 쓸 수 없고, 방을 지날 때마다 피로도가 +1 됩니다.
7. 입구에 도착하면 귀환 성공입니다.

데모는 귀환 경로를 보스방에서 입구까지 방 5개 전부로 합니다. 시간이 길면 3개로 줄입니다. [제안]

### 6-4. 정산 [기획]

- 소재가 자동으로 골드로 바뀝니다.
- 획득 골드의 일부가 빚 상환으로 자동 차감됩니다. 데모 비율은 50%입니다. [제안: 비율]
- 무기 강화는 초기화됩니다.
- 부채 전광판의 숫자가 줄어드는 연출을 보여 줍니다.
- 캐릭터별 빚 총액은 발렌 500만, 셰리 700만, 알레아 1,200만 골드를 제안합니다. 알레아는 도박 중독이라 가장 많게 했습니다. [제안]

## 12. HBEngine 구현 방식

10월 4일에 엔진 코드를 확인하고 화면 없이 시험 실행한 결과를 바탕으로 정했습니다.

| 기능 | 방법 |
| --- | --- |
| 이동 | TopDownMovement2D (시험 실행 확인) |
| 적 AI | 행동트리·FSM·NavigationGrid (시험 실행 확인) |
| 탄환·적 | Spawn Actor가 기본 도형만 만들 수 있습니다. 그래서 장면에 미리 배치한 객체를 재사용(풀링)합니다 (시험 실행 확인) |
| 검 베기 | Overlap Sphere와 내적으로 부채꼴을 판정합니다 |
| 회피·쿨타임·장전 | 타이머와 변수 |
| 동작 전환 | Play Animation으로 플립북 재생, 좌우는 방향별 플립북 |
| 방 전환 | 한 장면 안에 방 5개를 배치하고 카메라를 이동합니다. 거점↔던전은 Open Scene으로 넘어갑니다 |
| UI | 위젯(Text·ProgressBar·Button·Image) |
| 수치 | `balance.json` 하나에 모아 두고 조정 |

**엔진에 추가할 것**
1. 게임 중 마우스 커서의 월드 좌표와 마우스 버튼 입력을 받는 기능입니다. 지금은 게임 실행기가 키보드만 받습니다.
2. 이 작업을 하려면 엔진 저장소의 `research_only` 단계를 먼저 풀어야 합니다.

**확인이 남은 것:** 실제 창에서의 그림·UI·한글 글꼴·소리, 그리고 탄이 많을 때의 속도입니다. 한 장면의 객체 제한은 500개입니다.
