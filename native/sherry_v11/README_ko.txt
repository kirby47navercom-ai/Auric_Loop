셰리 모션 통합팩 v11 — 일반 이동 / 차징 공격

기획서의 차징 공격 2초 유지 기준을 적용했다.
활 기본 공격의 별도 1초 장전 규칙은 데이터에 분리했고, 기존 일반 공격 검토 에셋/450ms 발사는 유지했다.
완충 후 입력 해제 시 발사, 조기 해제 시 취소는 이 에셋의 연결용 동작 규약이다.
별도 차징 피해 배율·관통 개수·달리기 이동 배율은 문서에 명시되지 않아 임의로 확정하지 않았다.
design_rules.txt와 manifest.design_sources에 기획서 위치를 기록했다.

모든 캐릭터 프레임은 80×64, 발 기준 (40,58), Unity pivot(.5,.09375)다.
얼굴·머리·쌍 땋은 머리·바보털·의상·색상·SD 비율은 기존 v9를 유지했다.
왼손은 활, 오른손은 시위다. 캐릭터 이미지에는 화살을 넣지 않았다.

클립:
- idle: 활을 낮춰 잡은 이동 준비 자세, 방향별 1장.
- walk: 공격하지 않고 이동하는 4프레임. 기존 하체 보행과 1px 바운스 기준을 유지.
- run: 방향별 4프레임. 보폭 확대, 뒤로 접힌 발, 01/03의 공중 구간, 측면 1px 전방 자세.
  걷기를 빠르게 재생한 것만이 아니라 다리 자세를 재작성했다. 얼굴과 머리 크기는 바꾸지 않았다.
- normal_attack: 기존 6프레임과 검토 시간 [180,110,160,80,120,240]ms. 발사 시작450ms.
- charge_keyposes: 준비180ms→당기기320ms→조준/충전1500ms→발사80ms→복귀120ms→준비240ms.
  2초에 충전 완료. 유지 시간이 더 길면 charge_hold/ready_hold 루프를 사용한다.
- charge_hold / ready_hold: 최대 당김을 유지하고 망토·땋은 머리 끝만 작은 지연을 준 4프레임.

차징 이펙트:
기존 섬광탄 common/svg의 11→00 프레임을 역순으로 1/5 크기 투영했다.
가느다란 파장/입자가 사라지지 않게 원본 SVG 픽셀의 영역을 그리드에 모아 축소했다.
청록빛 파장과 황금빛 점이 작은 밝은 중심으로 수렴한다. 전체 화면 섬광은 쓰지 않았다.
32×32 이펙트/중앙 pivot(16,16), 0~800ms 이펙트 없음. 이후 12프레임×100ms=1200ms로 수렴한다. 첫 프레임은 빈 프레임이므로 실제 첫 빛은900ms부터 보인다.
차징/완충 이펙트는 모든 방향에서 캐릭터 전체보다 위에 합성한다. 발사 후 투사체/발사 FX의 가림은 기존 기준이다. 완충 후에는 작은 중심 빛을 유지한다.
UP 차징은 노출된 왼쪽 활 끝에 모인다. 발사 투사체는 기존 실제 중앙 받침에서 생성한다.
charge_fx.provenance에 원본 프레임 번호, 축소율, 원본 SVG SHA256을 기록했다.

발사:
일반/차징 화살 모두 최신 v3의 화살대 pivot을 사용한다. 최초 촉 돌출4px.
원본 캐릭터 좌표의 발사점 DOWN(43,42), LEFT(25,41), RIGHT(55,41), UP(39,34).
차징 화살은 같은 형태에 따뜻한 심만 추가했다. 속도140px/s는 검토용이며 최종 게임 수치가 아니다.
만화식 발사 FX는 기존 4프레임/120ms다. 생성 후 화살과 FX는 캐릭터를 따라가지 않는다.
UP는 몸·머리 뒤에서 시작하므로 투사체가 가려졌다가 북쪽으로 빠져나온다.
일반 공격 발사 이벤트450ms와 차징의 입력 해제 발사 이벤트를 혼용하지 않는다.

레이어 합성:
assets는 내용이 같은 SVG/PNG를 공유하는 저장소다. 경로를 manifest에서 읽는다.
각 clip.frames의 layer_refs와 draw_order로 합성하면 해당 png와 동일하다.
클립 합성 이미지는 오프셋이 이미 반영됐다. 추가 바운스 금지.
독립 상하체 합성은 source_inputs.upper의 중립 상체와 walk_lower/run_lower를 사용한다.
하체의 Y 바운스는 이미 구워졌다. 상체에 현재 gait_bob_px를 한 번만 더한다.
공격/차징 시작·완료·취소·복귀 때 걸음 시계를 초기화하거나 정지하지 않는다.
ordinary run의 전방1px 자세는 run 클립에 구워졌다. 공격 상체에는 다시 적용하지 않는다.

파일:
manifest.json: 모든 클립, 레이어/합성 경로, 관절, 좌표, 재생 시간, FX 출처.
assets: 편집 SVG와 동일 도트의 완전 투명 PNG. 중복 픽셀은 같은 파일을 공유한다.
sheets: 4방향 걷기/뛰기/차징 자세와 차징 FX SVG·PNG 시트.
previews: 원래 크기/최근접 확대의 걷기·뛰기·차징·걷기 중 차징·완충 유지·취소.
runtime: 상하체 독립 차징 시계와 기존 일반 공격/투사체 표시 예제.
tools/render_charge_previews.py: 현재 데이터로 최상위 차징/이동 중 차징 GIF를 재생성.
tools/export_bundle.py: 이전 팩 없이 현재 SVG를 PNG/클립 GIF로 재출력.
tools/validate_bundle.py: SVG·PNG·분리 합성·허리·발·원본 머리·프레임 시간 검사.

Unity에서는 Point 필터, no mipmaps, 같은 PPU와 manifest의 pivot을 적용한다.
SherryChargeFxLayer는 동일 SortingGroup 내 캐릭터 최고 sortingOrder+1로 차징/완충 빛을 정렬한다.
SherryChargeClock은 2초 조건과 독립 걸음 시계만 제공한다. 피해·관통·충돌·풀링은 게임에 연결해야 한다.
SherryChargeClock의 Shot은 이미 새 발사점과 바운스가 들어갔다. SherryShotSpawn.Release를 사용한다.
v9 SideAttackClock의 원래 발사점이면 ReleaseFromV9Event를 사용한다. 보정을 중복 적용하지 않는다.
Unity 실행 검증은 하지 않았다. 수치 검사와 시각 검토 결과는 validation.json에 구분해 기록했다.

용량은 공유 에셋, SVG 행 병합, JSON 공백 제거, 무손실 PNG/GIF 재압축으로 줄였다.
GIF는 최소20ms 프레임이며 검토용이다. 게임 이동속도나 공격속도를 임의로 확정하지 않았다.
