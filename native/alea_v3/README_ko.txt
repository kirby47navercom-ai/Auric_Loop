알레아 이동·공격·마법탄·명중 폭발 v3

기준 원본: alea_pixel_sprite_128x48.svg, Library version3.
모자·얼굴·머리카락의 도트와 색상은 유지했다. UP 머리 전체를 오른쪽2px 옮겨 목·몸통 중심에 맞췄다. 크기·색·형태를 변형하지 않았다.
모션을 위해 팔·손·고관절·다리와 가려진 의상 부분을 재작성했다.
캐릭터는 80×64px, 발 기준점(40,58), Unity pivot(.5,.09375).
원본 캐릭터를 확대하지 않고 각 방향을(24,13)에 배치했다.
우측 손은 항상 실제 오른손이다. 좌우 그림을 단순 반전해 손 역할을 바꾸지 않았다.

지팡이: 마법사 설정화 project_sources/07-176476.png 우측상단의 천구의 형태를 기준으로 수정했다.
갈색 자루 / 금색 고리2개 / 붉은 보석 / 매달린 카드와 녹색 천. 기존 픽셀 원본에는 지팡이가 없다.
모든 방향의 지팡이 보석과 손잡이, 발사 좌표를 최종 형상에 맞췄다.
정면에서 실제 오른손은 화면 왼쪽, 후면에서는 화면 오른쪽이다.
UP에서는 지팡이와 팔이 머리·몸·망토 뒤에 있고 실루엣 밖으로 나온 부분만 보인다.

구성
- 대기4방향, 걷기·뛰기 각각4방향×4프레임, 공격4방향×6프레임.
- 핵심 자세12장: prepare / aim / after_release.
- 투명 SVG/PNG 전신 프레임, 내용별 공유 분리 레이어, SVG/PNG 시트.
- 지팡이 발사 효과4프레임, 마법탄4방향×4프레임, 명중 폭발8프레임.
- 원래 크기/최근접 확대 GIF, 관절 표시 검수 PNG.

시계와 좌표
걷기[130,130,130,130]ms, 뛰기[90,90,90,90]ms.
공격[120,100,80,60,100,140]ms, 03번 프레임 시작300ms에 발사.
위 시간과 마법탄120px/s는 검토용이다. 게임 최종 공격속도·이동속도·재사용시간이 아니다.
독립 보행 시계는 공격 시작·종료에 초기화하지 않는다.
일반 이동 시 head/torso/arms/staff 등의 바운스는 [1,0,1,0]px다.
완성 PNG와 이동 하체에는 이미 적용됐다. 엔진에서 다시 더하지 않는다.
독립 합성: 현재 이동 프레임의 leg_left/leg_right/pelvis를 쓰고, 현재 공격 프레임의 나머지 레이어를 쓴다.
공격 상체는 중립 좌표이므로 현재 보행 바운스만 한 번 더한다. 일반 뛰기 전방1px 자세는 공격 상체에 중복하지 않는다.
방향별 골반 폭을 맞추고, 허리·고관절·어깨의 가려진 부분을 채워 부위끼리 겹치도록 했다.
옷자락은 뿌리를 유지하며 연속 변형하고 이웃 픽셀 연결을 보충했다.
지팡이를 잡지 않은 팔은 걷기1px/뛰기2px 범위로 이동 방향 앞뒤로 움직인다. 각 방향 draw_order를 따른다.
각 프레임의 joints와 muzzle_xy는 해당 완성 PNG 기준 좌표다. upper_offset_px는 구워진 이동량이다.

마법탄·효과는 캐릭터 그림에 포함되지 않는다.
projectiles[direction].spawn_socket_xy는 발사 직후 지팡이 보석 중심이다.
이동 중에는 발사 순간의 바운스를 한 번 적용하고 월드 좌표로 변환한다.
화면 좌표는 오른쪽+X / 아래+Y, Unity로 변환할 때Y 부호에 유의한다.
지팡이 끝은 총구가 아니라 마법을 방출하는 보석이다. 전후방은 원근에 맞게 투영했다.
탄을 생성한 뒤에는 캐릭터에서 분리해 이동한다.
충돌한 탄은 비활성화하고 충돌 지점에서 폭발을 한 번 재생한다.
폭발[30,40,50,60,70,80,90,80]ms=500ms, 마지막 프레임은 완전 투명이다.
폭발 그림이 있다고 범위 공격 판정을 자동으로 부여하지 않는다. 피해량·범위·상태이상은 미정이다.
공격→발사→명중 GIF의 표적까지40px와 충돌 시점은 시각 검토용 연출이다.

폴더
frames: 이름이 있는 게임용 프레임 SVG/PNG.
assets: 공유 분리 레이어, 독립 마법탄과 효과 SVG/PNG.
sheets: 투명 원본 시트 SVG/PNG.
previews: 배경을 깐 확대 GIF/PNG 및 투명 원래 크기 GIF. 게임용 텍스처가 아니다.
runtime: 독립 이동/공격 시계, 투사체 및 명중 효과 연결 예제. 실제 이동·피해 시스템은 연결해야 한다.
tools/build_assets.py: 이 ZIP 안의 원본 SVG에서 전체 데이터를 재생성한다.
tools/validate_assets.py: SVG/PNG, 레이어 합성, 허리 겹침, 손과 지팡이, 발사 좌표, 투명도 검사.

재생성: Python3 + Pillow + numpy, 검사에는 scipy가 추가로 필요하다.
python3 tools/build_assets.py
python3 tools/validate_assets.py
python3 tools/optimize_package.py
Unity: Point Filter / no mipmaps / 공통 PPU, 지정 pivot 사용.
Unity 실제 실행·충돌·피해 테스트는 하지 않았다. 수치 검사는 시각적 자연스러움의 보증과 별개다.

v3: 지팡이의 고리를3개에서2개로 줄이고 자루 명암·보석 잔도트·천의 금색 무늬를 정리했다. 카드와 녹색 천은 유지했다. 캐릭터·관절·모션·재생 시간·발사 좌표는 v2와 동일하다.
